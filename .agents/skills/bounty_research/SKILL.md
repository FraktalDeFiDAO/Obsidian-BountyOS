# Bounty Research Skill

## Description

Deep dive into bounty requirements, scope, payment details, and eligibility criteria.

## Research Areas

### Scope Analysis
- In-scope vs out-of-scope targets
- Allowed testing methods
- Prohibited activities
- Asset categories

### Payment Requirements
- Reward tiers and thresholds
- Minimum/maximum payouts
- Payment methods (crypto, bank, PayPal)
- Payment currency
- Bonus structures

### Eligibility
- Geographic restrictions
- Blacklist requirements
- Disclosure requirements
- NDA requirements
- Age restrictions

### Technical Requirements
- Bug severity levels
- Reproduction steps
- PoC requirements
- Report format
- Response timeframes

### Legal/Compliance
- Responsible disclosure policy
- Safe harbor provisions
- Authorization requirements
- Local laws compliance

## Output

Generate `requirements.md` with:
- All eligibility criteria
- Scope boundaries (clear in/out)
- Reward table by severity/type
- Submission requirements
- Timeline expectations
- Legal considerations

## Verification Steps

1. Read full program policy
2. Check for hidden requirements
3. Verify scope clarity
4. Confirm payment history
5. Check for recent changes
6. Review disclosure requirements
