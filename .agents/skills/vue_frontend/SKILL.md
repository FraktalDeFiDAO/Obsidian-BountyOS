# Vue.js Frontend Skill

## Description
Specialized skill for Vue.js 3 frontend development with Tailwind CSS, Pinia, and Viem.

## Capabilities
- Vue 3 + Composition API
- Tailwind CSS styling
- Pinia state management
- Vue Router navigation
- Viem wallet integration
- TypeScript development

## Tools
- npm / pnpm / yarn
- vite
- vue-cli
- eslint
- prettier

## File Patterns
- `frontend/**`
- `src/**/*.vue`
- `src/**/*.ts`
- `vite.config.ts`
- `tailwind.config.js`

## Commands
```bash
# Install dependencies
npm install

# Development server
npm run dev

# Build for production
npm run build

# Lint
npm run lint
npm run lint:fix

# Type check
npm run typecheck

# Run tests
npm run test
npm run test:coverage
```

## Triggers
- Changes to frontend files
- Package updates
- CI/CD pipeline runs

## Framework Versions
- Vue 3.x (latest)
- Tailwind CSS 4.x
- Pinia 2.x
- Vue Router 4.x
- Viem 2.x
- TypeScript 5.x
- Vite 5.x

## Best Practices
- Composition API with `<script setup>`
- TypeScript strict mode
- Component testing with Vitest
- E2E testing with Playwright
- ESLint + Prettier
