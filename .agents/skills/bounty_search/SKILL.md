## Search Parameters

- **Reward Range**: $100 - $50,000+
- **Difficulty**: Beginner to Expert
- **Skills**: Any (configurable)
- **Status**: Open, Active
- **Type**: Bug bounty, Feature, Documentation, Design, Security audit

## Usage

```
Search bounties by:
- Platform: github, hackerone, gitcoin, etc.
- Keywords: rust, solidity, react, etc.
- Reward: min/max amount
- Status: open, active
```

## Output Format

Return list of:
- Platform name
- Bounty ID/URL
- Title
- Reward range
- Difficulty/tier
- Skills required
- Deadline (if any)
- Application link
